# 术语表

本表定义 `SKILL.md`、`references/` 与维护文档共用的 17 个术语。定义只描述可判定的状态，不含操作建议。「不要写成」列列出常见误用词，这些词不进入运行时文件。

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 缺口 | 当前问题无法给出可执行下一步的那一个具体缺失，写成一句可判定是否闭合的陈述。 | 问题类型、标签 |
| 未判 | 入口的默认状态，表示尚未由探针产生类型；它是合法状态，不是错误。 | 待分类、不知道 |
| 探针 | 一次有成本上限的动作，用来产生判定所需的信息，结果会改变缺口类型或下一步。 | 调研、分析、搜索 |
| 门禁 | 一条缺口被标记为闭合前必须满足的断言；不满足就不能写「已闭合」。 | 检查项、建议、注意事项 |
| 缺口台账 | 逐行记录缺口的表，字段为缺口陈述、类型、已过门禁、代价、状态。 | 任务清单、待办列表 |
| 实例化 | 把通用答案改写为对当前用户成立的答案，方法是列出会翻转结论的私有条件。 | 个性化、补充说明 |
| 定位缺失 | 答案存在且有权威载体，但尚未取到可达的数值、条款或编号。 | 检索型、找资料 |
| 生成缺失 | 答案不存在，需要先造出可独立检查的中间物，并给出至少一条否决条件。 | 构造型、头脑风暴 |
| 证据缺失 | 答案取决于未来或无法直接观测，只能写出带 N、M、时点与止损线的可证伪断言。 | 实验型、试试看 |
| 参照类 | 与当前问题结构相同、结果已知的对象或领域；用来给出 base rate 基准，或作为可迁移解法的源域。 | 类比、相似案例 |
| 可逆化 | 把不可逆承诺拆成可撤回的最小步骤，使错误可以低成本回退。 | 降低风险、谨慎 |
| 止损线 | 开始前写定的停止条件，含最多花费的分钟数、金额或探针次数。 | 预算、心理准备 |
| 承重件 | `SKILL.md` 中一旦改动就会改变门禁、输出契约或步骤顺序的节。 | 重点、核心内容 |
| 过程文档 | 承载完整拆解过程的 Markdown 文档，固定 7 个二级标题，供人复查与下游解析。 | 报告、总结 |
| 推理门禁 | 一条因果结论标「已闭合」前必须通过的四项检查：关系式、比率基准、反证观测、断言强度；外部证据门禁只证明数据为真，不证明因果成立。 | 逻辑检查、合理性判断 |
| 反证观测 | 一条"若结论成立则不应出现"的可观测现象；观察到该现象即结论错，写不出反证则结论不可证伪。 | 反例、风险提示 |
| 叙事级 | 由故事、类比或常识推出、没有关系式的结论；状态只能是「未判」。 | 直觉、经验判断 |
