# 0001 探针先于分类

- 状态：已接受
- 日期：2026-10-25

## 问题

v1 在行动前用四个是/否问题判定形态。第一个问题问「这个答案，别人已经知道了吗」，对几乎任何问题都可以答「是」：任何问题都可能在某处有过某种答案。四个问题按顺序问，命中即停，于是大多数请求被归入「检索型」。

分类一旦完成就被当作输入，后续动作被固定。检索失败不会回到分类，只会继续换关键词。分类也不可证伪：没有哪个观察结果能要求改判。结果是标签在行动之前产生，而行动的质量无法反过来影响标签。

更具体地说，首问近乎恒真，顺序判定又是贪心的，两个机制叠加后，分类表上的四个分支只有一个在吸收请求。这不是分类标准不够细，而是分类发生在信息产生之前。

## 决策

入口状态固定为「未判」。先执行 P0 探针，成本上限 15 分钟，通常是一次定向检索加一次自问；缺口类型只由探针结果产生。判不出来时保持「未判」，下一步是把 P0 做完或换一个探针。

分类因此成为可证伪的输出：新的探针结果可以改变类型，也可以把一行拆成多行。未判是合法状态，不是错误，也不要求立刻消除。

## 备选方案

- 保留四问决策树：首问仍然近乎恒真，顺序判定仍然贪心；即使把四个问题写得更细，判定依然发生在信息之前，错误无法被观察。
- 先分类再行动：与 v1 同构，只是把标签换成新名词。分类仍然不可证伪，而且会让模型在检索之前锁定路径。
- 让模型自评置信度后再分类：置信度不是可观察量，无法作为门禁；输出仍然无法区分「跑过探针」与「觉得像某一类」。
- 只保留一个问题「答案是否已存在」：仍然在行动前分类，且把「存在」与「可达」混为一谈，而可达性正是定位门禁要检查的内容。

## 后果

类型由信息产生，错判可以通过下一次探针修正；未判允许先做成本最低的动作。

代价是每轮至少一次探针，启动比直接贴标签慢。对显式调用本方法的请求，这个成本可接受；普通问题不触发本方法，因此不受影响。

剩余风险是探针被写成泛泛搜索。P0 要求定向检索，定位门禁要求标准号、条款或编号，二者共同约束探针质量。
