# 反模式
> 何时读我：交付前自查，或用户反馈"这些都对但没用"，需要定位是哪一类失败。

反模式指：看起来完成了、实际把成本或选择推回给用户的输出。每条给出拦截信号、错在哪、改成什么。

## 自查表

| 反模式 | 看到就拦的信号 | 错在哪 | 改成什么 |
|---|---|---|---|
| 并列清单 | 出现"N 个方法、工具或项目"，彼此无取舍 | 把选择责任推回用户 | 只留一个下一步，其余降为候选并写明淘汰条件 |
| 跳过探针直接分析 | 第一段就是结论或分类标签 | 分类成了输入，门禁无处可挂 | 先跑 P0，把结果写进台账再谈类型 |
| 在污染语料里提炼 | 来源是营销号、榜单、种草、测评 | 结论的载体不可引用 | 换库，不改 query |
| 停在政策层或行业层 | 来源是政府通稿、评优名单、白皮书 | 权威不等于层级正确 | 下沉到标准号加数值，否则标"未闭合" |
| 字面类比 | 只因为两个词像就搬方案 | 约束没有对应 | 过三个约束检验，写清不搬的部分 |
| 纸面中间步骤 | 下一步是列清单、画矩阵、写大纲 | 不接触外部世界，不改变结论 | 换成跑基线、真读、真问、真测付费 |
| 无止损线 | 只有投入计划，没有停止条件 | 证伪后会自动加码 | 写死钱、时间、次数上限 |
| 散文式交付 | 全部是段落，没有台账或表格 | 承重件被段落包住，无法逐行检查 | 改成缺口台账加一个下一步加停止条件 |
| 只交最终结论 | 文档只有一段结论或一张表，没有探针与执行记录 | 读者无法判断有没有执行 | 按 §5 写 7 节过程文档，每节一个二级标题 |
| 强制三条并列路径 | 无论问题大小都输出"路径一、二、三" | 模板驱动，不是问题驱动 | 门禁已过就直接回答，一个缺口只给一个动作 |
| 无成本轴 | 有动作，没有分钟、元、人数、可逆性 | 无法排序，也无法拒绝 | 每个动作补四元组，估不出就不排 |
| 无执行者 | 下一步写"可以考虑""需要调研" | 把可拆解的动作丢回用户 | 执行者只能是模型、工具，或真正承担代价的人 |
| 无停止规则 | 没写什么时候停，或再做几次 | 探索无边界，沉没成本累积 | 写明满足什么即停，或探针轮数上限 |
| 领域语料偏斜 | 所有例子都来自同一个领域，通常是软件 | 结论只在那个领域成立，用户领域没被覆盖 | 至少补一个用户所在领域的例子，并标注哪些结论依赖领域 |

## 按缺口查

不知道当前该防哪一条时，先定缺口类型，再查对应行。

| 缺口 | 高频反模式 | 首个检查动作 |
|---|---|---|
| 定位缺失 | 在污染语料里提炼、停在政策层、无成本轴 | 打开来源，看层级和是否可引用 |
| 生成缺失 | 纸面中间步骤、散文式交付、领域语料偏斜 | 找中间物的检查动作，找不到就重做 |
| 证据缺失 | 无止损线、无停止规则、把决策当实验 | 看断言是否含 N、M、时点，不可逆是否已可逆化 |
| 实例化未做 | 并列清单、强制三条并列路径、无执行者 | 看是否出现用户私有约束和唯一执行者 |

## 高风险组合

单个反模式容易改，组合出现时通常意味着整份交付要重做。

| 组合 | 表现 | 处置 |
|---|---|---|
| 跳过探针加强制三条路径 | 没证据却给出多条并列方案 | 重做：先 P0，再定一个动作 |
| 停在政策层加无止损线 | 拿通稿当依据，还准备长期投入 | 重做：先下沉，再定止损 |
| 纸面中间步骤加无执行者 | 下一步是梳理需求，没人负责 | 重做：换成行动型，指定执行者 |
| 散文式交付加无成本轴 | 读起来完整，无法排序 | 重做：先出台账，再补代价 |

## 交付前最后三问

| 问 | 不合格的回答 | 合格的回答 |
|---|---|---|
| 下一步是谁做 | "可以研究一下" | "我做，用 X 工具，今天 30 分钟" |
| 什么时候停 | "看情况" | "3 轮探针后停" |
| 如果我错了 | 没写 | "最可能错在 Y，信号是 Z" |

三问有一问答不上，就不要交付。
